# v0.4.0-rc.1 — 统一 HTML 点选（测试版）

Codex、Claude Desktop、腾讯 WorkBuddy、豆包工作改用同一 HTML 点选页面：完整应用列表、多选、固定底部「确认所选应用，进入安装流程」。Claude Code 保留原生交互。

- 内嵌 MCP Apps 优先；不支持/未注册时打开同一套本地浏览器点选页面，不回退数字菜单。
- 保留三项旧选择、刷新草稿、简短标题、表格上下文、最后补充输入。
- 确认选择先进入按名称批准下载，安装仍另行确认；页面不自行执行 ADB。
- 添加有界等待与真实点击回传、会话锁、旧回调拒绝、初始化/完成状态区分。

验证：162 项自动化、5 项 Chrome 浏览器测试、Skill/plugin 校验通过。5 项中包含模拟 iframe 宿主测试，不是真实 Agent 内嵌验收。电脑控制连接失败，Codex/WorkBuddy/豆包本版真实安装与内嵌点击尚未完成；Claude 实机暂不验收，真实电视未操作。

**重要：ZIP 不会自动注册 MCP server。** 见本标签下 [README 安装步骤](https://github.com/SwainWong/android-tv-apps-helper/blob/v0.4.0-rc.1/README.md) 和 [测试报告](https://github.com/SwainWong/android-tv-apps-helper/blob/v0.4.0-rc.1/docs/platform-validation-v0.4.0-rc.1.md)。未配置 MCP 时先用无需额外依赖的浏览器模式。

这是预发布版本，不取代 v0.3.4 稳定版，也不进入稳定版自动更新提示。安装前校验附件 SHA256SUMS；保留旧会话与备份，仅替换本 Skill。客户端若不能维持后台等待或本地执行，会明确暂停而非冒充完成。
