# v0.3.4 — Codex 原生工具能力适配与 RA 图标

## 修正

- 全部目录应用可在原生组件中选择；移除硬编码禁用和“来源未预审不可下载”门槛。当贝使用已有 URL，补充 Emotn UI 官网链接；缺地址的应用确认后由 Agent 查找。仍保留实际文件检查和独立安装确认。
- 安装批准表和结果记录使用实际 APK 版本；与目录参考版本不同则高亮显示，不冒充安装了目录版本。

- Codex 支持实际暴露的 `request_user_input_async`（title + 字符串选项），同时保留允许使用时的同步 `request_user_input`。
- 启动前检查实际工具与模式限制；不再只按 Default / Plan 名称判断有无组件。
- 异步投递成功不是用户确认；保留待答题与展示 token，等待明确回答。
- 已阻塞的旧会话可切换到实际可用的替代原生工具，保留问题/进度，拒绝旧 token。
- 加入 RA 应用图标，修复平台 ZIP 漏打包 `agents/openai.yaml`；repository plugin 配置图标及 Logo。

## 验证边界

自动化、安装包校验与真实客户端 GUI 分开记录，见 [测试报告](../platform-validation.md)。当前 Codex 会话的异步工具调用已获接受；电脑控制服务报 `Sky Computer Use native pipe startup failed`，不能据此宣称整套安装→多轮弹框→图标显示已通过。未操作真实电视。
