# Android TV Apps Helper v0.3.0-rc.2

This release candidate is for live installation and dialogue validation on Codex, WorkBuddy, and Doubao Work before the final v0.3.0 release.

## Highlights

- Context-rich, table-first required questions with exact-answer locking.
- Automatic passive read-only precheck before the first business question.
- Cross-reinstallation update snooze for 24 hours.
- Evidence-gated connect, inspect, download, install, diagnose, Home, wallpaper, and finish checks.
- Native multi-select when available, with numbered text fallback and named confirmation.
- Model-aware ADB shutdown guidance and a conflict check before a successful safety finish.
- Official-source-only Dangbei workflow; ordinary users are never asked to find an APK.
- Shared harness packages for WorkBuddy, Doubao Work, and Claude.

Claude live validation remains deferred by user request.
