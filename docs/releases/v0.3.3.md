# Android TV Apps Helper v0.3.3 — 强选择

- 取消选项超限、需要输入和多选时的自动文字菜单降级：使用原生分页及点击添加/取消。
- IP／路径先显示“填写信息”入口，之后仍通过原生组件末尾补充输入；每一页保留返回或安全退出，视当前问题而定。
- 原生调用失败重试一次；宿主不提供工具或再次失败则暂停，不再让用户输入编号继续。
- 页码、选择集合和问题实例绑定展示 token，禁止旧页面或旧 CLI 绕过；上下文仍在组件外表格展示，标题保持简短。
- 修复常见路径 ADB 定位、发现结果回写，以及失败检查误显示零设备的问题。
- 四平台共享实现与自动化协议验证；本版客户端 GUI 和真实电视未实测，不以历史结果替代验收。
- 133 项测试通过；四平台解压包的多轮 CLI 回放覆盖检查失败后的原生分页，所有发布 ZIP 均提供 SHA-256 校验。Codex repository-plugin 与 Skill 的版本字段已统一。

请安装本版对应平台 ZIP 后新建对话，避免旧会话继续沿用 text_fallback 规则。
