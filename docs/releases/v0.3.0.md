# Android TV Apps Helper v0.3.0

This release turns the Skill into one deterministic, evidence-gated workflow for Codex, Tencent WorkBuddy China, Doubao Work, and Claude Desktop / Code.

## User-facing improvements

- Every turn begins with a compact status table, then shows the current blocker, remediation, exactly one required question, and explicit choices.
- Ambiguous answers such as “继续” or “好的” cannot advance the state machine; the same question and choices remain active.
- The first business turn performs a limited passive read-only precheck. It never scans a subnet, connects to a candidate, or downloads ADB/Platform-Tools without a later approved action.
- The task menu uses clear names, and application selection supports native multi-select or numbered text with a second named confirmation.
- User-visible plans have friendly names while immutable internal plan IDs remain hidden for integrity checks.
- Dangbei Market uses only its publisher-linked official source and never asks an ordinary user to find an APK.
- Home-key and wallpaper changes are independent approvals. The Skill shows the verified TV identity, compatibility risk, and the warning that firmware may restore wallpaper later.
- The finish menu has three non-overlapping choices. Restoring the session-start desktop requires a separate approval and an exact serial-bound HOME verification; it is never described as a factory desktop without separate identity evidence.
- Final results distinguish completed, attempted-but-incomplete, attention, pending, and skipped work in a Markdown table.
- After any ADB use, the Skill shows model-matched steps to close ADB/wireless debugging and developer mode, then checks for conflicting reachability evidence.
- Update checks ignore prereleases; declining an available stable update suppresses reminders for 24 hours.

## Validation

- 106 automated tests pass.
- WorkBuddy, Doubao Work, and Codex completed the bounded live acceptance scenario: installation, explicit invocation, automatic read-only precheck, invalid-answer locking, and safe exit. WorkBuddy's RC4 GitHub conversation install was blocked by a 502 proxy error and its in-client command path was stopped; the exact hash-verified ZIP was installed through a local filesystem fallback. Deeper app/Home/wallpaper/ADB-shutdown flows remain automated-only in this release run.
- Two independent user-view reviews found issues, the candidate was corrected, and both reviewers rechecked the final evidence boundaries.
- Claude packaging and shared-core contracts pass; live Claude validation was deferred by user request.
- No physical TV mutation, APK installation, Home-key change, wallpaper change, or on-site picture/sound/remote acceptance is claimed for this release run.

See `docs/platform-validation.md` for the evidence-separated report and known host limitations.
