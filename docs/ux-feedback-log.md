# Android TV Apps Helper：体验反馈持续记录

本文件用于持续收集真实 Agent 使用过程中暴露的问题。条目处于 `已收集` 状态时，仅代表问题和验收口径已经记录，不代表代码已修改或平台验证已完成。

## UX-001：提问前缺少上一轮结果、进度和解决指引

- 状态：已收集，待统一设计与实现
- 记录日期：2026-09-15
- 观察平台：腾讯 WorkBuddy（中国大陆版）
- 适用范围：Claude Desktop/Code、Codex、腾讯 WorkBuddy、豆包工作
- 证据：本轮用户提交的两张 WorkBuddy 截图。截图未作为仓库资源持久化。

### 观察到的问题

在设备发现阶段，WorkBuddy 展示了以下交互：

1. `S2-Q1` 首次未发现设备时，直接询问“接下来怎么做”，提供“重新扫描设备 / 提交电视 IP 地址 / 安全退出”。
2. `S2-Q1` 第三次仍未发现设备时，直接提供“扫描局域网查找电视 / 提交电视 IP 地址 / 再次扫描设备 / 安全退出”。

两轮都没有在问题之前说明：

- 上一轮执行了哪些发现方式，以及命令是否成功执行；
- 已重试多少次、发现了什么、排除了什么；
- 当前卡点是什么；
- 用户应如何在电视上开启 ADB，以及开启后如何继续。

这会让用户在相同选项之间反复尝试，却没有足够信息自行排除电视端设置问题。

### 期望行为

每一轮提问都必须先展示简短、可核对的上下文，然后再展示唯一一个“问题 + 选项”：

1. **上一轮结果**：做了什么检查、获得了什么结果；
2. **当前进度**：流程完成到哪一步、当前阻塞点是什么；
3. **处理指引**：用户现在可执行的具体解决步骤；
4. **本轮问题与选项**：优先使用平台原生选择组件，不支持时使用等价编号文字菜单。

首次提问没有“上一轮”时，也应明确写明“尚未执行设备检查”，并说明即将执行的检查范围。

### 未发现 ADB 设备时必须提供的文字指引

指引需使用用户可操作的语言，并提示不同品牌菜单名称可能不同：

1. 确认电视和运行 Agent 的电脑连接到同一个可信局域网；访客网络或开启了客户端隔离的 Wi-Fi 可能互相不可见。
2. 在电视中打开“设置”，进入“设备偏好设置 / 系统 / 关于本机”。
3. 连续点击“版本号 / Build”约 7 次，直到电视提示已开启开发者模式；部分电视会要求输入锁屏密码。
4. 返回“系统 / 开发者选项”，打开“USB 调试 / ADB 调试 / 网络调试 / 无线调试”中的对应开关。
5. 在“网络与互联网”或“关于本机”中查看电视 IP 地址。
6. Agent 发起连接后，在电视上核对并接受 RSA 调试授权提示；未授权、离线或仅端口可达都不能视为已连接。

如果平台支持图片展示，且能够获得与电视品牌、型号和系统版本匹配的可靠素材，可在文字步骤后附带标注截图或示意图。不得用不匹配的品牌界面冒充真实路径；缺少可靠截图时保留完整文字指引，并只在确有必要时用受约束选项询问品牌或系统类型。

### 跨平台内容对等要求

- 四个平台必须展示相同的结果摘要、进度、解决指引、问题 ID 和选项语义；仅允许因平台能力不同而改变展示形式。
- WorkBuddy、豆包工作若支持原生选择卡片，应把摘要和指引放在卡片问题之前或同一交互上下文中。
- Codex、Claude Desktop/Code 若无原生卡片，应输出等价的编号文字选项。
- 用户回答不明确、答非所问、使用旧问题的答案或输入格式错误时，不得推进状态或执行后续命令；应重新展示当前 `pending_question`，并保留更新后的结果摘要和处理指引。

### 待实现的数据字段建议

- `previous_result_summary`：上一轮执行与发现
- `progress_summary`：已完成步骤与当前阻塞
- `remediation_guidance`：与当前阻塞直接相关的解决步骤
- `evidence`：检查方式、次数和关键结果
- `visual_aid`：可选、来源可靠且与设备匹配的截图或示意图

### 验收标准

1. 每个交互回合在问题之前包含“上一轮结果、当前进度、处理指引”；首次回合明确尚未检查。
2. `S2` 零设备结果显示本轮实际采用的发现方式、执行结果和累计尝试次数。
3. 首次未发现设备时即提供简要 ADB 开启检查；重复未发现时展示完整的电视端 ADB 开启与授权指引，再给出选项。
4. 所有截图或示意图都有可靠来源且与目标设备场景相符；无法确认时不伪造截图。
5. Claude Desktop/Code、Codex、WorkBuddy、豆包工作的信息内容对等，只有 UI 载体可以不同。
6. 无效回答只重显当前问题，不改变流程状态，也不触发下一步命令。
7. 未经用户明确选择和范围确认，不扩大到局域网扫描；选择扫描时先说明扫描范围和用途。
