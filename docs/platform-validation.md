## 以下为 v0.3.3 历史记录（不是本版 GUI 证据）

日期：2026-09-16。本轮范围：修复用户反馈的“第一轮原生、第二轮五选项改文字输入”，以及关联的被动发现快照问题。

## 原因与修复

| 状态 | 问题 | 当前处理 |
|---|---|---|
| ✅ | 选项超限、短文本、大多选、禁用项导致 text_fallback | 原生分页、先选择后输入、原生逐项添加/取消；不可选原因外置表格 |
| ✅ | 原生工具失败后文字降级 | 同题原生重试一次，随后 native_blocked；保留问题、暂停操作 |
| ✅ | 旧 workflow-answer 命令绕过展示校验 | 与新命令使用同一 token 校验；缺少 token 的旧调用不能推进 |
| ✅ | IP 补充输入中的数字能触发隐藏选项 | 仅输入阶段允许值，且必须有指定前缀；返回/退出使用可见选项 |
| ✅ | ADB 不在 PATH 时误报未找到 | 复用项目已有 find_adb 常见路径，不自动下载安装 |
| ✅ | 设备发现与会话快照脱节 | workflow-discover 原子式串联本次执行和结果提交；失败显示未知而非零设备 |
| ✅ | 矛盾或不完整的发现证据 | 拒绝缺失列表、非零退出码、失败标记、缺少 devices -l、原始输出与列表不一致 |

## 回归场景

最终自动化：133 项测试通过。Skill/plugin 校验、Python 编译、JSON 解析、diff 空白检查与四平台包 SHA-256 校验通过。发布前另外发现 Codex repository-plugin 的版本字段仍停留在 0.3.0，已与本次 Skill 版本统一为 0.3.3，并新增双清单一致性回归。

每个平台从生成 ZIP 解压后运行 CLI：初始化 → 首题原生选择 → 第二题原生选择 → 回传检查失败 → 保留原生分页 → 点击更多选项且不产生动作。测试数据是离线 fixture，不是实际电视或客户端 GUI。

- 四平台：五选项全部可达，每页满足 2–3 / 2–4 选项上限，安全退出始终可点；所有工作流状态均生成有效原生页面。
- 翻页和添加/取消不改变业务状态、不创建动作；过期页面 callback 被拒绝。
- 填写 IP 先有入口；非法输入仍保留原生组件；有效值进入连接确认而非自动连接。
- 大应用列表跨页保留选择；点击完成后进入按名称确认，无下载批准。
- 原生错误重试和阻塞恢复；不能通过旧命令或编号绕过。
- 已发现候选电视替换旧零设备快照；本次执行失败保留未知设备数，重试次数递增。
- 独立代码审查复现了旧接口绕过、隐藏数字路由和失败快照三个问题，已修复并补充红绿回归；复核无剩余代码阻塞项。
