# Android TV Apps Helper v0.3.0 UX Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v0.3.0 with one deterministic, table-first, question-locked Android TV workflow across Codex, WorkBuddy, Doubao Work, and Claude packages, then live-validate the first three hosts and publish verified GitHub assets.

**Architecture:** Extend the existing Python standard-library harness with schema-3 state, fixed copy, structured interaction frames, update/precheck state, application selection, official-source resolution, device compatibility, and safety-finish modules. Keep platform adapters presentation-only and build all host ZIPs from the same canonical core and versioned data.

**Tech Stack:** Python 3.10+ standard library, unittest, Markdown, JSON, Git, GitHub CLI, native macOS host applications.

**Spec:** `docs/superpowers/specs/2026-09-15-v0.3.0-ux-hardening-design.md`

## Global Constraints

- Version is `0.3.0`; default update channel ignores prereleases.
- Every interactive frame contains a status table, current blocker/guidance, exactly one required question, fixed options, and accepted-answer format.
- Invalid, stale, missing, ambiguous, or malformed answers retain the exact pending question and execute no later command.
- Automatic precheck is read-only and passive; active subnet scanning or connection to an unselected address needs a separate approval.
- Every device command uses `adb -s <verified-serial>` and all mutation approvals are immutable.
- APK downloads require source, host, size, SHA-256, package/version, and signing-identity validation before installation planning.
- Clash Meta remains official-upstream-only; Dangbei uses a publisher-linked official source and is not mirrored without redistribution permission.
- Wallpaper and Home-key changes have separate compatibility risk gates and preserve the factory launcher.
- Every finish path reaches model-matched ADB/developer-mode shutdown guidance.
- Codex, WorkBuddy, Doubao Work, and Claude packages share identical core behavior; Claude live validation is deferred by user request.
