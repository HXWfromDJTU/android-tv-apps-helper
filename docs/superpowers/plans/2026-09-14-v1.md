# Android TV Apps Helper v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish a tested, public Codex plugin that provides a deterministic Android TV ADB and APK-installation workflow with structured-choice UI fallback.

**Architecture:** A repo-local Codex marketplace contains one plugin. A standard-library Python harness owns session checkpoints, question validation, ADB target binding, APK verification, and catalog policy; the Skill owns conversational orchestration and host UI adaptation.

**Tech Stack:** Codex plugin manifest, Markdown Skill, Python 3.10+ standard library, `unittest`, Android SDK Platform-Tools, GitHub CLI.

**Spec:** `docs/design.md`

## Global Constraints

- Every interactive turn has one required question and explicit options.
- UI failure falls back to the same question as a numbered text menu.
- Invalid answers never advance state or authorize mutations.
- Clash Meta downloads only from `github.com/MetaCubeX/ClashMetaForAndroid/releases`.
- Third-party APKs require provenance and redistribution permission before project hosting.
- Every ADB device command uses an explicit verified serial.
